# The whole map: where you are and where you want to go (2026-11-06, Ceetrix story 29)

Raised by Julian: "we should be able to show the user the whole map and where they are on it and where they want to go." Today the coach draws only the V1 stations, on one straight line. The coach model already reads the whole graph every turn (every station with its needs, from `stations.json`); the learner never sees it.

## What it is

- A **Map** button in the header opens the whole map full screen: all 141 stations and their 368 "needs" links, laid out once by a generator and committed, so the coach and (later) the book draw the same map.
- **Where you are:** the station of the step the coach showed last, or else the first station in the reading order not yet done. It has the same "You are here" marker as the three-stations figure.
- **Where you want to go:** tap any station to read what it unlocks and what it needs; a destination (26 of them) can be set as your goal. The route lights up: everything the goal needs that isn't done yet. The coach reads the goal and the route on its next turn.
- Covered stations are drawn at full strength, the rest at half (Julian's rule for the three-stations figure, point 4). Criticality keeps its colour and shape (grey circle, amber diamond, red triangle).
- Zoom (buttons, the wheel, a trackpad pinch) and pan (drag); Escape closes. Touch-screen pinch is not built.

## Where it reaches

| Place | What changes | What stays |
|---|---|---|
| `curriculum/map-layout.json` (new) | Every station's position and every link's path, generated by `apps/app/scripts/layout-map.mjs` (elkjs, layered, left to right, needs before what needs them) and committed | `stations.json` itself: no station, link, proof or wording changes |
| `fixtures/curriculum/map-layout.json` (new) | The same for the tests' frozen copy | Its stations |
| `curriculum/validate.py` | The layout must place exactly the stations in `stations.json` and draw exactly their links (rule MAP_LAYOUT) | Every other rule |
| `progress.json` | A `goal` field (destination id and time), written only by the goal route, by atomic rename. Restart coach moves it with the rest | Status rules: a goal never changes any status |
| CLAUDE.md, `docs/design.md` | The goal joins the list of what writes `progress.json` | Everything else |
| The coach (middleware) | Each turn it is told the learner's goal and the route, as ids | The prompt's rules and tools; the coach is not told to act on the goal, it decides |
| `curriculum/scope.json`, lessons, stories, chapters, figures, `map.json` | Nothing | |
| The book (`panel/`, chapter 0's "the map we'll use") | Nothing in this story. A print drawing from the same layout is the natural follow-up (decision 4) | |

No words a learner reads in lessons change, so the term clock and voice rules are untouched; the map's own few words (button names, "You are here") go through the voice test.

## Decisions that are the author's

1. **The layout.** Generated, not hand-drawn. It is a starting point: positions are in a JSON file you can edit, and the generator only rewrites them when asked (`make map-layout`). A tube-map look (areas as coloured lines, 45-degree bends) would need hand placement; not attempted.
2. **What counts as covered** (full strength): reported, assisted, verified and skipped. Read and rehearsed count as not yet.
3. **Goals are destinations only.** Any station can be tapped and read; only the 26 destinations can be a goal, because the curriculum's trails run to destinations (`docs/spec.md`). One goal at a time.
4. **The book.** Whether chapter 0's map is this drawing (a print SVG from the same layout), and what it shows.
5. **The coach and the goal.** It is told the goal and the route; whether and how it brings them up is the model's call, per the agentic-flow rule. A tool for the learner to set a goal by asking in chat is not in this story.

## What was done

All of the above, through `make check` (MAP_LAYOUT passes for both curricula). Two changes after seeing it in the browser:

- **It opens on "You are here" at a readable size**, not fitted. Fitted, all 141 stations were unreadable specks; Fit is one press away.
- **Choosing a goal frames the route** (where you are and every station to the goal), because the route ran off the screen.

Also: links not on the route are faint; tapping a station highlights the links into and out of it; each station's whole row is its tap target.
