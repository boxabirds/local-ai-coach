Agentic testing: four levels and their tests

The test discipline is cumulative — each level inherits everything from the levels below it and adds new categories.

Agentic systems aren't one thing. The testing discipline shifts qualitatively at each of four levels. Click a level card to see which test categories apply at that level. A Level 4 system runs all categories from Levels 1, 2, 3, and 4 — not just the Level 4 ones.

The cumulative principle

A Level 4 agent runs Level 1 tests for its host code and configuration, Level 2 tests for its generated content and judge calibration, Level 3 tests for its tool dispatching, trajectory shape, and security architecture, and Level 4 tests for its termination decisions. Each level adds categories rather than replacing the previous ones.

Most production failures cluster around the highest level the system operates at — which is why teams building Level 4 systems with only Level 2 testing ("we're using an LLM, so we need evals") ship things that fail in ways their tests can't see.
